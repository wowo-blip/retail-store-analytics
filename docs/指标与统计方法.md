# 指标、客户分层与统计方法

## 财务指标

所有经营指标先应用统一日期和国家筛选，再排除 `transaction_type = excluded`。

- 销售额：`sale` 行的 `quantity × unit_price` 之和。
- 退货金额：`return` 行带符号金额的绝对值之和。
- 净收入：销售额减退货金额。
- 销售订单：至少有一条 `sale` 行的不同发票号数量。
- 退货相关发票：至少有一条 `return` 行的不同发票号数量。
- 平均订单金额：销售额 / 销售订单数。
- 退货金额率：退货金额 / 销售额。

服务代码（例如 POST、BANK CHARGES）计入财务总额，但不进入商品排行榜。

## 客户 ID 覆盖

客户 ID 行覆盖率的分母是所有有效销售和退货行，分子是其中客户 ID 非空的行。缺失客户 ID 的收入仍计入公司财务指标，但不进入：

- 客户数；
- 复购率；
- RFM；
- cohort 留存；
- 客户收入集中度。

这意味着客户表净收入之和不应强行与公司净收入完全对账。

## RFM

- Recency：分析结束日减客户最后销售日期的天数，越小越好。
- Frequency：不同销售发票数。
- Monetary：客户销售额减客户退货金额。

三项分别按当前筛选客户的五分位打 1–5 分。分层规则：

- 高价值活跃：R、F、M 均较高；
- 忠诚客户：频次高且近期活跃；
- 高价值流失风险：过去价值或频次较高，但近期不活跃；
- 新近客户：最近购买但频次仍低；
- 潜力客户：近期活跃但尚未进入高频高价值；
- 沉睡/低频：其余客户。

分层用于形成调查和实验优先级，不自动等于营销动作。

## Cohort 活跃

客户 cohort 是其在当前筛选范围内的首次购买月份。M+N 留存表示该客户在首次购买后的第 N 个自然月再次出现销售发票。

- 不要求客户逐月连续活跃；
- 看板只显示首月客户至少 50 的 cohort；
- 未来尚不可观测月份显示为空，而不是 0；
- 日期筛选改变时，cohort 定义随之重算。

## Wilson 区间

市场退货信号使用：

```text
退货相关发票占比 = 退货相关发票 /（销售发票 + 退货相关发票）
```

对该比例计算 95% Wilson score interval。与简单的 `p ± 1.96×标准误` 相比，Wilson 区间在小样本和接近 0/1 的比例下更稳定。

看板只展示至少 30 个商业发票的市场，但 30 不是统计显著性的保证，只是避免极小分母占据主图。

由于取消发票无法稳定关联到原销售发票，该比例被称为“退货相关发票占比”，不称为严格订单退货概率。

## 客户集中度

收入集中度仅对净收入为正的已识别客户计算：按客户净收入降序排序，取前 10% 客户净收入除以全部正净收入客户的总额。

排除负净收入客户是为了避免分母被大额净退货扭曲；报告必须同时说明这一条件，不能简称为“全部客户前 10% 贡献”。

## 不支持的推断

当前数据不能直接回答：

- 退货由商品质量、物流、欺诈还是客户偏好导致；
- 某次营销活动提升了销售或复购；
- 客户不再出现是否等于真实流失；
- 2009—2011 年样本能否代表当前市场；
- 国际市场差异是否来自定价、税费、物流或获客策略。

因此项目提供描述性指标、分层和不确定性，不作因果承诺。
